# opencode Telegram Bot

Телеграм-бот для управления сессиями [opencode](https://opencode.ai) на одном или
нескольких инстансах. Позволяет читать и отправлять сообщения в сессии, создавать
новые сессии, переключаться между инстансами, менять модель, подтверждать запросы
разрешений и прерывать генерацию.

## Запуск

```sh
cp config.example.json config.json
# отредактируйте config.json и .env (см. ниже)
python3 bot.py
```

Для каждого инстанса opencode должен быть поднят HTTP-сервер, например:

```sh
opencode --port 4096
```

## Конфигурация

`config.json` (не коммитится, в git только `config.example.json`):

```json
{
  "instances": [
    { "name": "vps", "url": "http://127.0.0.1:4096", "password_env": "OC_VPS_PASSWORD" },
    { "name": "home", "url": "http://127.0.0.1:4097", "password_env": "OC_HOME_PASSWORD" }
  ],
  "send_replies_to_telegram": true,
  "agent": ""
}
```

`.env` (не коммитится):

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | токен Telegram-бота от @BotFather |
| `TELEGRAM_API` | базовый URL Bot API (по умолчанию `https://api.telegram.org`) |
| `TELEGRAM_PROXY` | HTTP(S)-прокси для запросов к Telegram, необязательно |
| `OC_VPS_PASSWORD`, `OC_HOME_PASSWORD` | пароли инстансов opencode |

Токен и пароли хранятся только в `.env` / `config.json`, оба файла в `.gitignore`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/menu` | меню управления с кнопками |
| `/help` | список всех команд |
| `/sessions` | список последних сессий с выбором |
| `/where` | id текущей сессии и готовая команда `attach` |
| `/new` | создать новую сессию и закрепить её за чатом |
| `/abort` | прервать генерацию в текущей сессии |
| `/clear` | открепить сессию (вернуться к авто-выбору последней) |
| `/instances` | список инстансов с выбором |
| `/use <name>` | переключить активный инстанс, например `/use home` |
| `/model` | выбрать модель для текущей сессии |
| `/model <provider/id>` | сменить модель сразу, например `/model opencode/gpt-5.4` |
| `/stop` | прервать генерацию во всех инстансах |
| `/version` | pid, время запуска, git-ревизия и активный инстанс |

Любое сообщение без `/` отправляется в текущую сессию opencode. Если сессия не
закреплена, используется последняя активная сессия инстанса.

## Кнопки

Меню (`/start`, `/menu`) содержит:

- **Сессии** — последние сессии; нажатие закрепляет выбранную за чатом.
- **Новая сессия** — создаёт и закрепляет новую сессию.
- **Прервать (abort)** — прерывает генерацию в текущей сессии.
- **Открепить сессию** — снимает закрепление.
- **Где я** — id сессии и готовая команда `attach`.
- **Инстансы** — список инстансов; нажатие делает инстанс активным.
- **Модель** — выбор провайдера и модели для текущей сессии.
- **Стоп во все** — abort во всех инстансах.
- **Помощь** — список команд.

При запросе разрешения от opencode бот присылает кнопки **Разрешить**,
**Всегда** и **Отклонить** для текущей сессии.

Список команд также регистрируется в Telegram (`setMyCommands`) при запуске,
поэтому доступен в штатном меню команд рядом с полем ввода.

## Состояние

Закреплённые сессии и активный инстанс хранятся в `bot_state.json`
(не коммитится). Файл можно безопасно удалить — бот вернётся к значениям по
умолчанию.
